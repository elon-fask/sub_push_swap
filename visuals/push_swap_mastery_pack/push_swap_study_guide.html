02 · runtime behavior

Program flow, main to stdout

One pipeline: parse → measure → dispatch → solve → print. Solvers never print; they call operation wrappers that print and count.

Mental model: solvers are decision makers; operation wrappers are the only writers. The bonus checker calls the same primitives but skips writers, which is why it validates any solver output.

04 · data structure

The circular ring buffer, visually

Both stacks are fixed-capacity integer arrays. The top element never moves; a head index marks where the top sits, and logical offset k resolves to physical (head + k) mod capacity.

Physical vs logical view (capacity 8, 5 active)

Invariants to memorize

push_tophead = (head − 1 + cap) % cap; write; size++
pop_topread data[head]; head = (head + 1) % cap; size--
swap_topexchange data[head] with data[(head+1)%cap]
rotate (ra/rb)save top; advance head; write saved value at new bottom (head + size − 1) % cap
reverse_rotate (rra/rrb)read bottom; back head up; write bottom value at new head
Defense nuance: unlike a pure head-pointer ring, this implementation copies one value on rotate so that the ring stays dense between head and bottom. Empty stacks never rotate; size < 2 returns STACK_UNCHANGED.

Real code — stack_rotate.c (condensed)

t_stack_status stack_rotate(t_stack *stack)
{
    int             top_value;
    size_t          bottom_index;

    if (stack->size < 2)
        return (STACK_UNCHANGED);
    top_value = stack->data[stack->head];
    ++stack->head;
    if (stack->head == stack->capacity)
        stack->head = 0;
    bottom_index = (stack->head + stack->size - 1) % stack->capacity;
    stack->data[bottom_index] = top_value;
    return (STACK_CHANGED);
}

Measured wrapper pattern (operation_pb.c)

void operation_pb(t_stacks *stacks, t_stats *stats)
{
    int value;

    if (stack_pop_top(&stacks->a, &value) == STACK_UNCHANGED)
        return;
    stack_push_top(&stacks->b, value);
    ft_printf("pb\n");
    record_operation(stats, OPERATION_PB);
}

Empty or single-element stacks silently return STACK_UNCHANGED, so invalid no-op instructions are never emitted — matching the subject's "operation on empty stack does nothing" rule.
06 · input validation

Parsing: options first, integers second

Two independent parsers: parse_options consumes flags and collects plain strings; parse_operands splits those strings on spaces and validates every integer before it touches the stack.

Overflow-safe integer parse (the key defense point)

// inverse test before every multiply-add
if (magnitude > (limit - digit) / 10UL)
    return (-1);
magnitude = magnitude * 10UL + digit;
  • Positive limit = INT_MAX; negative limit accepts exactly -2147483648.
  • A trailing non-digit (12a), a bare sign (+, -), and empty/whitespace-only tokens all fail.
  • Duplicate scan: linear search over data[0..size) before appending.

Supported options (extras; subject core needs none)

shortlongeffect
-s--simpleforce selection sort
-m--mediumforce chunk sort
-c--complexforce turk sort
-b--benchreport counters on stderr
--—end of options; rest are numbers

Failure → Error\n on stderr, exit 1

No args → silent exit 0; valid integers including both INT limits accepted; quoted strings with several numbers accepted, e.g. "1 5 2" 4 "3".

07 · decision layer

Disorder ratio and adaptive dispatch

Before solving, the program counts inverted pairs. The ratio picks the solver; an explicit flag overrides; a sorted stack exits before any move.

Metric

disorder = inversions / C(n, 2)
         = #{(i,j) : i<j and a[i] > a[j]} / (n(n-1)/2)

Demo array 7 2 9 1 4 11 8 3 12 5 10 6 has 26 inversions among 66 pairs → 39.39%. Real output: [bench] disorder: 39.39%.

ratioclassstrategy
0.0sorted; early exit—
< 0.2almost sortedselection
0.2 – 0.5medium scramblechunk
≥ 0.5highly disorderedturk

Dispatch code (orchestrator_dispatch.c)

static t_strategy select_adaptive_strategy(double disorder)
{
    if (disorder < 0.2)
        return (STRATEGY_SIMPLE);
    if (disorder < 0.5)
        return (STRATEGY_MEDIUM);
    return (STRATEGY_COMPLEX);
}
Logic in dispatch_strategy: explicit non-adaptive flag runs that solver (and records the ratio only under -b); otherwise the ratio chooses; every choice is recorded with stats_set_selected_strategy.

08b · solver 2 · simple

Selection sort — O(n²)

Repeatedly move the minimum of A to B; when A empties, push everything back. Best when almost sorted, or as the N ≤ 5 path.

-s selection (measured)
45 ops

Demo breakdown: pb 12, pa 12, ra 13, rra 8. Rotations dominate because every minimum may sit far from the top; this is why the dispatcher reserves it for ratio < 0.2.

08c · solver 3 · medium

Chunk sort — rank, partition, restore O(n√n)

Values are compressed to ranks 0…n−1, split into √n-wide ranges, moved to B range by range, then pulled back in descending order.

Step 1 — rank compression (in-place heapsort)

value123456789101112
rank01234567891011

Ranks survive in chunk_item { value, physical_index }; originals are restored with items[rank].value at the end.

Step 2 — width: smallest k with k² > n; width = 2(k − 1)

n = 12 → k = 4 (16 > 12) → width = 6 → ranges [0,6) and [6,12). For n = 100, width ≈ 20; n = 500, width ≈ 44.

Step 3 — partition A → B

  • Scan A: a rank inside the current range is pb; otherwise ra to rotate onward.
  • If the rank is in the lower half of the range, issue rb right after pb, sinking it deep in B; upper-half ranks stay near B's top.

Step 4 — restore B → A: pop the maximum each time

Descending pops leave A ascending; then ranks are swapped back to original values. Measured demo: pb 12, pa 12, ra 6, rb 6, rrb 5 = 41 ops.

Robustness note: if the rank-array allocation fails, chunk_sort falls back to turk_sort rather than aborting — a detail worth mentioning in defense.
08d · solver 4 · complex

Turk sort — cheapest move first (greedy)

For every candidate element the program computes where it belongs and how many rotations both stacks need, chooses the global minimum, and executes shared rotations first.

Targets

directionorder kept in targetlanding rule
A → BB circular descendingpredecessor = largest value < v; if none → above B's maximum
B → AA circular ascendingsuccessor = smallest value > v; if none → above A's minimum

Move record (t_turk_move)

source index, target index, source/target rotation counts, total cost, direction flags, source_is_a.

Four cost combinations

A directionB directioncost
rarbmax(src, tgt) — shared rr
rrarrbmax(src, tgt) — shared rrr
rarrbsrc + tgt — no sharing
rrarbsrc + tgt — no sharing
Worked mini-state: B = 8 5 3 1, candidate 6 at A offset 2; predecessor 5 at B offset 1. Both forward → max(2,1) = 2; both reverse → max(3,3) = 3; mixed → 5 or 4. Cheapest: two forward rotations, then push.

Execution order inside turk_execute_move

1 · shared rr / rrr
2 · leftover source rotations
3 · leftover target rotations
4 · push (pb / pa)

Main phases

  1. While A > 3: cheapest A→B move, executed and pushed.
  2. Sort the last 3 in A with the minimal internal sort_three.
  3. While B > 0: cheapest B→A move with successor targets.
  4. Rotate A so its minimum sits at offset 0 (turk_rotate_minimum_to_top).

Measured demo: pb 9, pa 9, sa 1, ra 3, rb 3, rra 5, rrb 3, rrr 1 = 34 ops. On N = 100 runs, shared rotations reach ≈ 68 rr + 50 rrr per permutation — the main source of Turk's low move count.

10 · bonus

Checker bonus program

A second binary built with make bonus. It reuses parsing and stack primitives; it reads instructions from stdin and reports OK / KO, never emitting moves of its own.

dispatch branchhandlesexecutors
line[0] == 's'sa sb ssexecute_swap
line[0] == 'p'pa pbexecute_push → transfer_top
line[0]=='r' && line[1]=='r' && line[2]rra rrb rrrexecute_reverse_rotate
line[0] == 'r'ra rb rrexecute_rotate
Empty-stack push: transfer_top returns early on STACK_UNCHANGED — no crash, no print. On an invalid instruction the line is freed and GNL static buffers cleaned up before Error\n.

13 · rehearsal

Defense Q&A (condensed; full answers in docs/defense_qa.md)

Q1 · Why a circular array instead of linked nodes? One allocation per ring; push/pop/rotate are index math modulo capacity; contiguous ints give cache locality; no per-node pointer overhead or repeated malloc/free.
Q2 · How does rra work without shifting elements? Read the bottom value, back head up modulo capacity, write that value at the new head; the old bottom becomes the top in O(1) with one value copy.
Q3 · How is integer overflow prevented? In parse_magnitude the inverse test magnitude > (limit − digit) / 10 runs before multiply-add; negative limit accepts exactly −2147483648.
Q4 · What is the disorder ratio and where do thresholds sit? Inversions / C(n,2). Below 0.2 selection; 0.2–0.5 chunk; ≥ 0.5 turk. Sorted input exits before any solver; explicit flags override selection; bench records the ratio regardless.
Q5 · How does Turk choose a move? Target predecessor in B (descending) or successor in A (ascending); evaluate four direction pairs: same direction shares rr/rrr at max cost, opposite directions cost the sum; global minimum executed with shared rotations first, leftovers second, push last.
Q6 · Why ranks in chunk sort? Raw ints span INT_MIN…INT_MAX; ranks 0…n−1 make range partitioning arithmetic and collision-free; originals are kept in item records and restored after sorting.
Q7 · What does ss / rr / rrr guarantee? One combined mnemonic printed when at least one side changes; checker executes both primitives; sharing cuts move count (≈118 shared rotations per N=100 Turk run in measured samples).
Q8 · What happens on empty-stack pushes? Pop returns STACK_UNCHANGED; wrapper prints nothing and records nothing; checker no-ops silently — matching subject semantics.
Q9 · Memory safety walkthrough? Two rings allocated in initialize_stacks; operand array in parser; chunk items calloc-freed on every path including the Turk fallback; destroy_stacks and destroy_parse_result run after solve; checker frees GNL buffers on error.
Q10 · Weak points to preempt? Selection is O(n²) (low-disorder use only); disorder scan reads data[] directly and relies on head = 0 pre-solve; chunk falls back to Turk on allocation failure; some N=500 random runs sit near 5500–5800 while staying under the 8500 pass band.
